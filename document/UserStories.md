# User Stories for Music Course Platform

## **Authentication and User Management**

- **As a teacher**, I want to register an account so that I can offer my teaching services on the platform.
- **As a learner**, I want to create an account so that I can find and book music lessons.
- **As a registered user**, I want to log into my account so that I can access the platform features.
- **As a user**, I want to log out of my account so that my session ends securely.

---

## **Teacher Profile Management**

- **As a music teacher**, I want to create my teaching profile so that students can learn about my experience and decide to book lessons.
- **As a teacher**, I want to create my teaching session (a profile) so that students can see my available lessons and book them.
- **As a teacher**, I want a personalized dashboard so that I can quickly access my profile, schedule, and bookings.
- **As a teacher**, I want to see my upcoming lessons on my dashboard so that I can prepare for them and not miss any scheduled lessons.

---

## **Teacher Availability and Time Slot Management**

- **As a music teacher**, I want to add available time slots to my schedule so that students can see when I am available and book lessons.
- **As a music teacher**, I want to view all my scheduled time slots so that I can manage my availability and bookings.
- **As a music teacher**, I want to delete available time slots so that I can remove times when I am no longer available.

---

## **Teacher Search and Discovery**

- **As a learner**, I want to search for teachers by instrument so that I can find teachers who teach what I want to learn.
- **As a learner**, I want to filter teachers by their availability so that I can find teachers who have open slots when I am free.
- **As a learner**, I want to see clear search results so that I can easily compare teachers and make a booking decision.
- **As a learner**, I want to view a teacher's complete profile so that I can decide if they are suitable for my learning needs.

---

## **Lesson Booking**

- **As a learner**, I want to book a lesson with a teacher so that I can secure a time slot for my music lesson.
- **As a learner**, I want to view all my booked lessons so that I can keep track of my upcoming music lessons.
- **As a teacher**, I want to view all lessons booked with me so that I can prepare for upcoming lessons and manage my schedule.
- **As a learner**, I want to receive immediate confirmation after booking so that I know my booking was successful.
- **As a learner**, I want to cancel a booked lesson so that I can free up the time slot if I cannot attend.

---

## **Session Management**

- **As a user (teacher or learner)**, I want to see my upcoming lessons on my dashboard so that I don't miss any scheduled lessons.

---

## **Project Management and Finalization**

- **As a team**, we need to ensure all planned features are fully implemented and operational through testing and debugging before the final demonstration.
- **As a team**, we need to create a fully functional GUI Docker image that can run the JavaFX application on Windows via X11/Xming display forwarding.
- **As a team**, we need to push the final working GUI Docker image to Docker Hub, verify it is publicly accessible, and test it via Docker Play.
- **As a team**, we need to finalize the unit test suite, ensure all tests pass, and generate the final JaCoCo coverage report for the presentation.
- **As a team**, we need to create the final presentation slides following the lecturer's instructions for the demo session.
- **As a team**, we need to present the finalized prototype to classmates, demonstrate all features including Docker deployment, and collect feedback.
- **As a team**, we need to write the Sprint 4 Review Report, documenting achievements, challenges, and the final product status for submission.
- **As a team**, we need to finalize the GitHub repository and Trello board, ensuring they are complete, clean, and ready for final submission.
